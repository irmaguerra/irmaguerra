## 📈 Lo que estoy construyendo

Un **sistema de inventario para organizaciones humanitarias** que gestiona:

- Inventario de consumibles con trazabilidad por lote y kardex inmutable.
- Módulo de activos fijos con códigos QR, etiquetas y ciclo de vida completo.
- Control de entradas, almacenes, socios y proyectos.
- Sistema de permisos por roles y aislamiento de datos multi-organización.

Diseñado con arquitectura modular, priorizando la trazabilidad, la seguridad de los datos y la experiencia de usuario.
